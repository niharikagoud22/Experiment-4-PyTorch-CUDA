\# Experiment 4: Project Repository and PyTorch-CUDA



\## Aim

To create and manage a deep learning project using Git and GitHub and configure a PyTorch-CUDA environment for GPU computation.



\## Tools Used

\- Python

\- Git

\- GitHub

\- PyTorch

\- Kaggle Notebook

\- NVIDIA GPU



\## Project Structure

\- dataset: Dataset files

\- models: Model files

\- notebooks: Experiment notebooks

\- results: Output files

\- train.py: Training program

\- inference.py: Inference program

\- requirements.txt: Project dependencies



\## Outcome

Created a structured project repository, performed Git version-control operations, and verified GPU computation using PyTorch and CUDA.
